# MissionGuard AI frontend

Next.js, React, TypeScript, Tailwind CSS, and Firebase power the dashboard, simulator, authentication, and saved history.

See the [root README](../README.md) for setup, environment variables, API endpoints, testing, deployment, and limitations.

From this directory, use `npm ci`, configure `.env.local` using `.env.example`, then run `npm run dev`. Validate changes with `npm run lint`, `npx tsc --noEmit`, and `npm run build`.

MissionGuard is an educational portfolio prototype, not operational launch guidance.
