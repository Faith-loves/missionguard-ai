# Screenshot capture checklist

Add real captures from the running MissionGuard application to this directory:

| Suggested filename | View |
| --- | --- |
| `dashboard.png` | Main dashboard with the educational disclaimer |
| `risk-cards.png` | Score, readiness, classification, and factor breakdown |
| `kp-chart.png` | Recent NOAA planetary Kp chart |
| `simulator.png` | What-if controls and the hypothetical assessment |
| `explanation.png` | Granite explanation or clearly labeled deterministic fallback |
| `history.png` | Saved live assessment and simulation, including saved inputs |
| `login.png` | Firebase sign-in page with empty credentials |

Use an authorized test account and hide personal email addresses. Never include tokens, passwords, developer-console secrets, or environment files. Capture desktop and at least one narrow mobile viewport. Keep fallback labels, simulation notices, and data availability messages visible; do not present a mocked test fixture as live data.

After adding actual image files, link them from the root README using relative Markdown image paths. These filenames are suggestions, not existing screenshots.
